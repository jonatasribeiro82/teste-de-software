# Projeto de Teste de Software - Automação QA

Este repositório contém a estrutura básica de um projeto Node.js utilizando TypeScript, criado para a entrega da atividade.

## O que foi desenvolvido neste projeto:
- **Estrutura básica Node.js:** Inicialização do projeto e configuração do ambiente com `package.json`.
- **Variáveis:** Aplicação de diferentes tipos de variáveis e tipagem estática nos exercícios práticos.
- **Funções e Loops:** Implementação de lógicas utilizando estruturas de repetição (for, while) para resolver os desafios propostos na aula.
